Trabajo de Fin de Máster

Xarxa Anglesola

Una red vecinal para prestar lo que ya tenemos: catálogo, reservas y chat en tiempo real. Aplicación real, desplegada y en uso.

Web app Next.js · PostgreSQL · Socket.IO Vercel + Railway

El problema

El barrio ya comparte. Falta la infraestructura.

Hoy

El préstamo vecinal vive en grupos de WhatsApp, notas de portería y memoria. Los objetos se pierden de vista; no hay estado ni histórico.

Lo que hace falta

Un lugar común donde publicar, reservar, hablar y saber si aquello está libre, reservado o en préstamo — en el móvil y en el escritorio.

La solución

Una app de barrio, no un marketplace.

Sin pagos ni anuncios. El valor es la confianza entre vecinos y un ciclo de préstamo claro.

Publicar→ Reservar→ Chat privado→ Préstamo→ Devolución

Funcionalidades

Lo que el usuario puede hacer

Cuenta

Nickname + contraseña o Google. Recuperar clave. Completar perfil OAuth.

Catálogo

Fotos, filtros, cuadrícula o lista, estado visible (reservado / en préstamo).

Favoritos

Guardar productos y avisar al propietario.

Chat

Sala general y DM ligado a un producto, persistido en la base de datos.

Alertas

Campana in-app y Web Push, con preferencias por tipo y palabras clave.

Datos

Exportar o borrar la cuenta (RGPD), cookies, términos y privacidad.

Stack

Tecnologías del máster, aplicadas.

Frontend

React 18, TypeScript, Tailwind, next-intl (ca / es / en), PWA, tema claro/oscuro, onboarding.

Backend

Route Handlers, Prisma, sesiones HMAC + NextAuth (Google), validación de entrada, headers de seguridad.

Calidad

Vitest (unitario) y Playwright (e2e) sobre auth, productos, favoritos, reservas y reset de contraseña.

Ops

Vercel + Railway, variables de entorno documentadas, Blob para archivos, PostgreSQL en producción.

Tiempo real

El chat no es un añadido: es el puente del préstamo.

  • La reserva abre (o enlaza) una conversación privada con el propietario.
  • Los mensajes se guardan en PostgreSQL y se reemiten por Socket.IO.
  • Cambios de estado del producto (reservado / préstamo) llegan al resto de clientes sin recargar.
  • Si el navegador no está abierto, Web Push lleva el aviso al dispositivo.

Confianza

Seguridad y datos personales.

Auth y API

Cookies de sesión firmadas, OAuth Google, contraseñas con bcrypt, validación de uploads, CSP y HSTS en producción.

RGPD

Banner de cookies, páginas legales, exportación de datos y eliminación de cuenta desde Configuración.

Criterio del TFM

Original, útil y puesto a prueba.

  • Real: flujo completo de usuario, no solo pantallas.
  • Diferenciador: préstamo vecinal con estado + chat, no un e-commerce genérico.
  • Conocimientos del máster: full-stack, tiempo real, auth, despliegue, tests, i18n, RGPD.
  • Valor personal: una herramienta para un barrio concreto, no un CRUD de ejemplo.
